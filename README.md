## 🌟 Featured Projects

### 📝 [Akshar Blog Platform](https://github.com/MrBengaliHacker/akshar-blog-platform)
A production-oriented, full-stack blogging platform built with React 19, Express 5, and MongoDB Atlas, featuring secure authentication, AI-powered content assistance, and interactive API documentation.

- **Security & Authentication:** Dual-token JWT architecture with 15-minute access tokens, `httpOnly` refresh cookies, refresh-token rotation, MongoDB TTL-based session cleanup, DOMPurify XSS protection, and rate limiting.
- **AI Integration:** Google Gemini-powered editing and writing assistant with daily usage tracking and tier-based quotas.
- **API Documentation:** Interactive REST API documentation and testing using Swagger UI.
- **Links:** [🌐 Live Application](https://akshar-blog-platform.vercel.app) • [📖 Swagger API Docs](https://akshar-blog-platform.onrender.com/api/v1/docs) • [💻 Codebase](https://github.com/MrBengaliHacker/akshar-blog-platform)

### 🎯 [ResumeLens — AI Resume & ATS Analyzer](https://github.com/MrBengaliHacker/resumelens)
An AI-powered developer tool built with React 19, TypeScript, and Zustand that evaluates resumes against job descriptions, calculates ATS match scores, and provides structured improvement recommendations.

- **Client-Side Document Pipeline:** Integrated `PDF.js` to render high-fidelity resume previews directly in the browser and extract document text before cloud transmission.
- **AI Evaluation Engine:** Orchestrated structured prompt flows with Claude Sonnet via Puter.js to generate ATS match metrics, keyword gap analysis, and tailored bullet-point recommendations.
- **State & Storage Architecture:** Managed application state and upload workflows using Zustand 5, with user history and session persistence through Puter KV storage and file system APIs.
- **Links:** [🌐 Live Application](https://resumelens-tau.vercel.app) • [💻 Codebase](https://github.com/MrBengaliHacker/resumelens)
